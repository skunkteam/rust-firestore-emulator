# src

## Overview
Root library module for `emulator-database`, implementing `FirestoreProject` multi-database management and snapshot export/import orchestration, `FirestoreDatabase` CRUD/query/aggregation/transaction operations with packed atomic settings, real-time `Listener` target streams, configuration (`FirestoreConfig`, `DatabaseEdition`, `DatabaseConcurrencyMode`, `DatabaseSettings`), error mapping (`GenericDatabaseError`), internal concurrency/validation utilities, and the pure in-memory `.fsemu` `snapshot/` codec and streaming plan module.

## Interface
- `[lib.rs]`: Re-exports `pub use config::*;`, `pub use database::*;`, `pub use error::GenericDatabaseError;`, `pub use project::FirestoreProject;`, and public modules `pub mod config;` and `pub mod snapshot;`.
- `[config.rs:FirestoreConfig]`: `pub struct FirestoreConfig { pub long_contention_timeout: bool, pub default_enterprise: bool, pub transaction_idle_timeout: Option<Duration>, pub transaction_max_lifetime: Option<Duration> }` (`with_transaction_timeouts`, `with_transaction_idle_timeout`, `with_transaction_max_lifetime`).
- `[config.rs:DatabaseEdition]`, `[config.rs:DatabaseConcurrencyMode]`, `[config.rs:DatabaseSettings]`: Shared configuration enums (`DatabaseEdition::{Standard, Enterprise}` implementing `fmt::Display` as `"STANDARD"`/`"ENTERPRISE"` and `DatabaseConcurrencyMode::{Pessimistic, Optimistic}`, both deriving `Serialize`/`Deserialize` with `#[serde(rename_all = "UPPERCASE")]`) and `pub struct DatabaseSettings { pub edition: DatabaseEdition, pub concurrency_mode: DatabaseConcurrencyMode }` with `pub const fn for_edition(edition: DatabaseEdition) -> Self` (`Standard -> Pessimistic`, `Enterprise -> Optimistic`).
- `[project.rs:FirestoreProject]`: `pub struct FirestoreProject` (`new`, `send_project_event`, `subscribe_project_events`, `subscribe_contention_events`, `contention_subscriber_count`, `contention_snapshot`, `clear_contention_history`, `clear_database`, `get_existing_database`, `database`, `pub(crate) database_for_listener`, `database_names`, `listen`, `prepare_export`, `import_snapshot`) coordinating databases (`RwLock<HashMap<RootRef, Arc<FirestoreDatabase>>>`), serialized snapshot imports (`import_lock: Mutex<()>`, `next_import_id: AtomicU64`), contention broadcasts, and `ProjectEvent` broadcasts.
- `[database.rs:FirestoreDatabase]`: `pub struct FirestoreDatabase` (`new`, `pub(crate) new_with_config_and_collections`, `get_doc`, `peek_doc_meta`, `list_collection_ids`, `pub(crate) get_all_collections`, `run_query`, `write`, `create_doc`, `update_doc`, `delete_doc`, `delete_prefix`, `list_docs`, `get_read_time`, `new_txn`, `rollback`, `rollback_sync`, `send_event`, `subscribe`, `settings`, `update_settings`, `enterprise_edition`, `set_enterprise_edition`, `optimistic_concurrency`, `set_optimistic_concurrency`, `set_config`, `pub(crate) MAX_EVENT_BACKLOG`), paired with `[database/aggregation.rs:FirestoreDatabase::run_aggregation_query]`, `[database/commit.rs:FirestoreDatabase::commit]` (unified transactional and non-transactional `commit(writes, Option<TransactionId>)`), public modules `event`, `field_path`, `pipeline`, `projection`, `query`, `read_consistency`, `reference`, and crate-internal modules `aggregation`, `collection`, `validation`, `document`, `lock`, `timeouts`, `transaction`, `vector`.
- `[error.rs:EXPIRED_TRANSACTION_MSG]`, `[error.rs:GenericDatabaseError]`, `[error.rs:AbortReason]`, `[error.rs:CommitError]`: `pub enum GenericDatabaseError { Aborted, AlreadyExists, Cancelled, Internal, InvalidArgument, InvalidReference, FailedPrecondition, NotFound, NotImplemented }` (`grpc_code`, `From<GenericDatabaseError> for tonic::Status`, `From<GenericDatabaseError> for googleapis::google::rpc::Status`), crate-internal `EXPIRED_TRANSACTION_MSG` (`"The referenced transaction has expired or is no longer valid."`) and typed `AbortReason` (`Wounded`, `UpgradeContention`, `ReadTimeout`, `WriteTimeout`, `OptimisticWriteSkew`, `TransactionExpired`, `DatabaseCleared`, `DatabaseDropped`), and `CommitError { Aborted(AbortReason), Other(GenericDatabaseError) }` preserving typed abort causes into `CommitSlotGuard::abort_commit`.
- `[listener.rs:Listener]`: `pub(crate) struct Listener` (`start`) with `MAX_RESET_RETRIES = 3`, cleared-database TOCTOU retry helpers (`is_cleared_retryable`, `reacquire_database`, `reset_target`, `edition_mismatch_error`), `ListenerTarget::required_enterprise`, and `QueryTarget::ensure_matching_edition`.
- `[utils.rs]`: `pub(crate) trait RwLockHashMapExt` (`get_or_insert`) and macros `unimplemented!`, `required_option!`, `unimplemented_option!`, `unimplemented_collection!`, `unimplemented_bool!`.
- Subdirectories:
  - [database](./database/README.md): Core document, collection, reference, field path, projection, query, aggregation, pipeline, Wound-Wait lock manager ([lock](./database/lock/README.md)), unified commit orchestration (`commit.rs`), read consistency, and transaction lifecycle/registry ([transaction](./database/transaction/README.md)).
  - [snapshot](./snapshot/README.md): Pure in-memory, I/O-free `.fsemu` binary container format constants, `SnapshotError`, `ImportedDatabase`, `ImportSummary`, `ExportSnapshotPlan`, Proto3 wire schema (`wire.rs`), and streaming `SnapshotEncoder` / `SnapshotDecoder` (`codec.rs`).

## Invariants
- `[database.rs:FirestoreDatabase::settings]` / `[database.rs:EventChannel]` / `[database.rs:pack_settings]` / `[database.rs:unpack_settings]`: `FirestoreDatabase` packs `DatabaseEdition` (`BIT_ENTERPRISE = 0b01`) and `DatabaseConcurrencyMode` (`BIT_OPTIMISTIC = 0b10`) into a single `settings: AtomicU8`. Lock-free `settings()` (plus `enterprise_edition()` and `optimistic_concurrency()`) loads with `Ordering::Acquire` for tear-free reads, while `pub fn update_settings(&self, update: impl FnOnce(&mut DatabaseSettings)) -> DatabaseSettings` (used by `set_config`, `set_enterprise_edition`, and `set_optimistic_concurrency`) loads (`Ordering::Acquire`) and stores (`Ordering::Release`) under `self.events.lock()`, returning the committed `DatabaseSettings` and emitting `ProjectEvent::DatabaseConfigChanged` iff `next != prev && !matches!(*events, EventChannel::Cleared)`. `events` starts in `EventChannel::Idle` in `new_with_config_and_collections` (avoiding eager `MAX_EVENT_BACKLOG`-slot broadcast allocation on idle or imported databases), lazily allocates `EventChannel::Active(broadcast::channel(MAX_EVENT_BACKLOG).0)` only on the first `subscribe()`, and transitions to `EventChannel::Cleared` in `mark_cleared()` (dropping any `Active` sender so `subscribe()` returns a closed channel and `send_event` becomes a no-op). `new_with_config_and_collections` constructs detached databases with arbitrary `(edition, concurrency_mode)` and pre-populated collections, binds `locks.set_reaper(Arc::downgrade(&db))`, wires `ContentionBroadcaster` via `LockManager::with_broadcaster`, and suppresses `DatabaseConfigChanged` events.
- `[project.rs:FirestoreProject::prepare_export]` & `[project.rs:FirestoreProject::import_snapshot]`: `prepare_export` acquires `databases.read().await` once, deduplicates and sorts explicit `Some(roots)` targets (returning `GenericDatabaseError::NotFound` without lazily creating missing databases) or collects all sorted existing databases on `None`, stamps `snapshot_time = Timestamp::now()`, clones `Arc<FirestoreDatabase>` handles, reads `db.settings()` atomically, and releases the lock before streaming `ExportSnapshotPlan::into_stream()`. `import_snapshot` acquires `import_lock.try_lock()` (`SnapshotError::ImportInProgress`) **before** constructing `SnapshotDecoder` (so Rust drop order frees decoder/prepared buffers before releasing `_import_guard` on failure or cancellation), decodes and validates all frames in one streaming pass without holding `databases` or document locks, fast-returns `ImportSummary { databases: Vec::new(), import_id: None }` for zero-database snapshots without acquiring `databases.write().await` or calling `Timestamp::now()`, and on non-empty snapshots allocates a monotonic `import_id` from `next_import_id: AtomicU64` (starting at `1`), marks every replaced database cleared via `old_db.mark_cleared()` inside `databases.write().await` **before** stamping `import_time = Timestamp::now()`, materializes detached `FirestoreDatabase` instances via `PreparedDatabase::into_database(self, import_time)`, emits `ProjectEvent::DatabaseReplaced { database, import_id }` (plus `ContentionSseEvent::DatabaseCleared`) or `ProjectEvent::DatabaseCreated { database, import_id: Some(import_id) }` (non-import lazy creations emit `import_id: None`), releases the write lock, and drops `replaced_dbs` inline before releasing `import_lock`.
- `[database/commit.rs:FirestoreDatabase::commit]` & `[database/transaction/registry.rs:RunningTransactions]`: Request-level write parsing and validation (`ValidatedWrite::parse` via `validate_commit_writes`) runs **before** `take_for_commit(id, has_writes)` so validation errors keep both `ReadWrite` and `ReadOnly` transactions `Active`. On `Active(ReadOnly)`, `has_writes == true` transitions to `Closed { outcome: AbortedOrRolledBack, read_only: true }` and returns `InvalidArgument`, whereas `has_writes == false` transitions immediately to `Closed { outcome: Committed, read_only: true }`. On `Active(ReadWrite)`, `take_for_commit` calls `session.mark_commit_started()` and returns an RAII `CommitSlotGuard` holding the `Committing` slot while acquiring sorted target `WriteLease`s (`acquire_or_upgrade_write` / `acquire_write`), verifying pessimistic `ReadObservation` upgrade contention and optimistic `check_concurrency_violations()`, fast-pathing `writes.is_empty()` via `LockSession::commit_empty()` instead of acquiring `CommitSeal` and `apply_sealed_commit`, and otherwise sealing all locks into a `CommitSeal` and atomically applying mutations inside `DocumentMeta::apply_sealed_commit`. Non-transactional commits (`None`) bypass `RunningTransactions` completely (`target_docs.is_empty()` fast-paths without locks; `target_docs.len() == 1` uses `LockPriority::NextSeq` with `can_wound = false, woundable = false`; multi-document `WriteBatch` acquires all targets concurrently via `acquire_writes_all` with `LockPriority::NextSeq`, `can_wound = true, woundable = true`, and bounded exponential server-side retry on `Wounded`).
- `[database.rs:FirestoreDatabase]`: `new_txn` rejects explicit non-`Unspecified` `TransactionOptions.read_write.concurrency_mode` with `NotImplemented`; `ensure_owns_root` / `ensure_owns_doc` reject mismatched database roots with `InvalidArgument`; `list_docs` rejects `page_size < 0`, `show_missing && !order_by.trim().is_empty()`, and Enterprise Edition non-empty `order_by` with `InvalidArgument`, rejects `show_missing && collection_id.is_empty()` with `NotImplemented`, parses Standard `order_by` (supporting backtick/backslash escaping and rejecting invalid directions), decodes and validates stateless versioned Protobuf/`base64::URL_SAFE_NO_PAD` `page_token` cursors (`<= 2 MiB`, bound to `(parent, collection_id, show_missing, order_by, mask)` and effective order arity without binding `page_size`/`ReadConsistency`) before `Query::once`, applies `start_at` + `limit(page_size + 1)` with unprojected boundary extraction when `!show_missing`, and when `show_missing` is `true`, filters existing matches via `googleapis::cmp_reference_paths` before projection and calls `Query::missing_docs_at` (evaluating MVCC snapshots on `Default`, `ReadTime`, `ReadOnly`, and `Optimistic` subcollections while keeping `get_doc` ancestor verification under `Transaction`, skipping ancestors `<= after_cursor` before collection/document checks), merging and sorting via `googleapis::cmp_reference_paths`; `list_collection_ids` rejects `Ref::Collection` parents, `page_size < 0`, and invalid/mismatched/cross-RPC `base64::URL_SAFE_NO_PAD` Protobuf `page_token`s with `InvalidArgument`, returns lexicographically ordered collection IDs, and emits an empty `next_page_token` on exact-fit final pages.
- `[database/aggregation.rs:FirestoreDatabase::run_aggregation_query]`: Enforces pre-execution validation order (`ensure_owns_root` -> `Query::from_structured` -> aggregation compilation -> Standard `Query::require_existing_fields` -> `Query::once`), allowing valid `StructuredQuery.select` (validated via `Projection::try_from` and ignored during execution, while invalid `select` paths return `InvalidArgument`), requiring `1..=5` aggregations on Standard (`1..=64` on Enterprise) each with an `Operator` (`Count`, `Sum`, or `Avg`), rejecting `Count.up_to < 0` on Standard (`up_to == 0` returns `0`) and rejecting any non-`None` `Count.up_to` on Enterprise (`"The `count_up_to(...)` accumulator is not supported in Enterprise edition."`), assigning omitted/empty aliases sequentially (`field_1`, `field_2`, ... incrementing only when empty) while rejecting explicit aliases exceeding `1_500` UTF-8 bytes on both editions, rejecting reserved explicit aliases (`reference::is_reserved_name`) on Standard only, rejecting duplicate resolved aliases on both editions, validating `SUM`/`AVG` fields (`into_non_reserved_field_path` on Standard rejecting `__name__`, empty segments, and reserved `__...__` segments; allowing `FieldReference::DocumentName` and `FieldPath::validate_non_reserved_allowing_doc_name` on Enterprise, returning `nullValue` when targeting `__name__`), enforcing Standard Edition's implicit field-existence filter (`Query::require_existing_fields` in `Query::matches_prefilters` for `SUM`/`AVG` `FieldPath`s), and recording structured tracing span fields (`agg_count`, `enterprise`, `matched_docs`).
- `[listener.rs:Listener]` & `[listener.rs:QueryTarget::ensure_matching_edition]`: Listen streams only support `AddTarget` with `target_id == 1` (`TARGET_ID`), a single active target per stream, and a single document in `DocumentsTarget`, enforce cross-database ownership (`InvalidArgument`) on query/document paths and `validate_read_time` on `ResumeType::ReadTime`, and reject `RemoveTarget`, `once`, `expected_count`, `labels`, and `request_options` as unimplemented. `Listener::process_event` ignores events on cleared databases (both before reading and on non-`FailedPrecondition` errors); `BroadcastStreamRecvError::Lagged` re-acquires and re-subscribes in `self.database_events` before calling `reset` so an already-replaced `old_db` channel cannot later deliver a duplicate `(db_name, None)` reset; `reset`, `set_document`, and `set_query` accept owned `Arc<FirestoreDatabase>` handles, send `TargetChangeType::Add` once before retrying, recompute `read_time` per retry in `set_document`, and retry cleared-database TOCTOU races up to `MAX_RESET_RETRIES` (`3`) only when `is_cleared_retryable` (`database.is_cleared() && matches!(err, GenericDatabaseError::Aborted(_))`) holds. When re-acquiring a database on channel closure or lag, `reacquire_database` calls `project.database_for_listener(db_name, target.required_enterprise()).await`: if the database was cleared and `required_enterprise` differs from `project.default_enterprise`, `database_for_listener` returns `None` without resurrecting a ghost database or emitting `ProjectEvent::DatabaseCreated`, and `reacquire_database` returns `Err(edition_mismatch_error(...))` (`FailedPrecondition` + `tracing::error!`). `QueryTarget::ensure_matching_edition` also runs at the start of both `QueryTarget::reset` and `QueryTarget::process_event` (before the `event.update_time <= self.last_reset_time` early return) and, when `self.query.enterprise_edition() != database.enterprise_edition()`, invokes `edition_mismatch_error` (`tracing::error!` + `GenericDatabaseError::FailedPrecondition`).

## Side Effects
- `[project.rs:FirestoreProject]`: Lazily allocates and caches `Arc<FirestoreDatabase>` instances in an async `RwLock<HashMap<RootRef, Arc<FirestoreDatabase>>>` (except `database_for_listener` when absent and mismatched with `default_enterprise`), marks cleared or replaced databases via `database.mark_cleared()` (immediately closing `DatabaseEvent` subscribers, aborting stale in-flight writes/commits with `Aborted`, and suppressing stale database/config events), swaps imported databases atomically under `import_lock`, and broadcasts lifecycle and mutation `ProjectEvent` notifications (`DatabaseCreated`, `DatabaseCleared`, `DatabaseReplaced`, `DatabaseConfigChanged`, `DocumentsChanged`) and `ContentionSseEvent` invalidations over bounded broadcast channels (`MAX_PROJECT_EVENT_BACKLOG = 1024`).
- `[database.rs:FirestoreDatabase]`: Parses and validates writes pre-lock into `ValidatedWrite` in `[database/validation.rs:ValidatedWrite::parse]` (with post-transform merged field validation in `[database/commit.rs:FirestoreDatabase::stage_write]`, `StagedDocument`), mutates in-memory collection and document state during `write`, `create_doc`, `update_doc`, `delete_doc`, `delete_prefix`, and `commit`, and sends `Arc<DatabaseEvent>` updates over `events: std::sync::Mutex<EventChannel>` (emitting `ProjectEvent::DocumentsChanged` whenever `!event.updates.is_empty()` in both `Idle` and `Active` states, lazily creating the `MAX_EVENT_BACKLOG = 1024` broadcast channel only upon `subscribe()`, and suppressing all events in `EventChannel::Cleared` once `mark_cleared()` runs).
- `[listener.rs:Listener::start]`: Spawns a background `tokio::spawn` task that subscribes to database broadcast streams, emits `ListenResponse` messages over a bounded `mpsc::channel(16)`, exits immediately on `self.sender.closed()`, re-subscribes and resets targets on `BroadcastStreamRecvError::Lagged`, reconnects immediately with bounded TOCTOU retries when `clear_database` or `import_snapshot` calls `mark_cleared()` (or when a database is dropped), and logs `tracing::error!` + terminates with `FailedPrecondition` on `QueryTarget` edition mismatch.
- `[utils.rs:unimplemented]`: Logs unsupported feature messages via `tracing::warn!`.
