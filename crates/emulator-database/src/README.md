# src

## Overview
Root library module for `emulator-database`, implementing `FirestoreProject` multi-database management, `FirestoreDatabase` CRUD/query/aggregation/transaction operations, real-time `Listener` target streams, configuration (`FirestoreConfig`), error mapping (`GenericDatabaseError`), and internal concurrency/validation utilities.

## Interface
- `[lib.rs]`: Re-exports `pub use config::*;`, `pub use database::*;`, `pub use error::GenericDatabaseError;`, `pub use project::FirestoreProject;`, and `pub mod config;`.
- `[config.rs:FirestoreConfig]`: `pub struct FirestoreConfig { pub long_contention_timeout: bool, pub default_enterprise: bool }`
- `[project.rs:FirestoreProject]`: `pub struct FirestoreProject` (`new`, `send_project_event`, `subscribe_project_events`, `clear_database`, `database`, `database_names`, `listen`)
- `[database.rs:FirestoreDatabase]`: `pub struct FirestoreDatabase` (`new`, `get_doc`, `peek_doc_meta`, `get_collection_ids`, `get_document_ids`, `run_query`, `run_aggregation_query`, `write`, `create_doc`, `update_doc`, `delete_doc`, `delete_prefix`, `list_docs`, `get_read_time`, `new_txn`, `rollback`, `rollback_sync`, `send_event`, `subscribe`, `enterprise_edition`, `set_enterprise_edition`, `optimistic_concurrency`, `set_optimistic_concurrency`, `set_config`), paired with `[database/commit.rs:FirestoreDatabase::commit]` (unified transactional and non-transactional `commit(writes, Option<TransactionId>)`) and public modules `event`, `field_path`, `pipeline`, `projection`, `query`, `read_consistency`, `reference`.
- `[error.rs:GenericDatabaseError]`, `[error.rs:AbortReason]`, `[error.rs:CommitError]`: `pub enum GenericDatabaseError { Aborted, AlreadyExists, Cancelled, Internal, InvalidArgument, InvalidReference, FailedPrecondition, NotFound, NotImplemented }` (`grpc_code`, `From<GenericDatabaseError> for tonic::Status`, `From<GenericDatabaseError> for googleapis::google::rpc::Status`), crate-internal typed `AbortReason` (`Wounded`, `UpgradeContention`, `ReadTimeout`, `WriteTimeout`, `OptimisticWriteSkew`, `DatabaseCleared`, `DatabaseDropped`), and `CommitError { Aborted(AbortReason), Other(GenericDatabaseError) }` preserving typed abort causes into `CommitSlotGuard::abort_commit`.
- `[listener.rs:Listener]`: `pub(crate) struct Listener` (`start`)
- `[utils.rs]`: `pub(crate) trait RwLockHashMapExt` (`get_or_insert`) and macros `unimplemented!`, `required_option!`, `unimplemented_option!`, `unimplemented_collection!`, `unimplemented_bool!`.
- Subdirectories:
  - [database](./database/README.md): Core document, collection, reference, field path, projection, query, pipeline, Wound-Wait lock manager ([lock](./database/lock/README.md)), unified commit orchestration (`commit.rs`), read consistency, and transaction lifecycle/registry ([transaction](./database/transaction/README.md)).

## Invariants
- `[database/commit.rs:FirestoreDatabase::commit]` & `[database/transaction/registry.rs:RunningTransactions]`: Request-level write validation (`get_doc_name_from_write`, `ensure_owns_doc`, `validation::validate_write` via `validate_commit_writes`) runs **before** `take_for_commit(id, has_writes)` so validation errors keep both `ReadWrite` and `ReadOnly` transactions `Active`. On `Active(ReadOnly)`, `has_writes == true` transitions to `Closed { outcome: AbortedOrRolledBack, read_only: true }` and returns `InvalidArgument`, whereas `has_writes == false` transitions immediately to `Closed { outcome: Committed, read_only: true }`. On `Active(ReadWrite)`, `take_for_commit` calls `session.mark_commit_started()` and returns an RAII `CommitSlotGuard` holding the `Committing` slot while acquiring sorted target `WriteLease`s (`acquire_or_upgrade_write` / `acquire_write`), verifying pessimistic `ReadObservation` upgrade contention and optimistic `check_concurrency_violations()`, sealing all locks into a `CommitSeal`, and atomically applying mutations inside `DocumentMeta::apply_sealed_commit`. Non-transactional commits (`None`) bypass `RunningTransactions` completely (`target_docs.is_empty()` fast-paths without locks; `target_docs.len() == 1` uses `LockPriority::NextSeq` with `can_wound = false, woundable = false`; multi-document `WriteBatch` acquires all targets concurrently via `acquire_writes_all` with `LockPriority::NextSeq`, `can_wound = true, woundable = true`, and bounded exponential server-side retry on `Wounded`).
- `[database.rs:FirestoreDatabase::run_aggregation_query]`: `StructuredQuery.select` must be `None`, and every `Aggregation` must define an `Operator` (`Count`, `Sum`, or `Avg`).
- `[listener.rs:Listener::process_request]`: Listen streams only support `AddTarget` with `target_id == 1` (`TARGET_ID`), a single active target per stream, and a single document in `DocumentsTarget`; `RemoveTarget`, `once`, `expected_count`, and `labels` are rejected as unimplemented.

## Side Effects
- `[project.rs:FirestoreProject]`: Lazily allocates and caches `Arc<FirestoreDatabase>` instances in an async `RwLock<HashMap<RootRef, Arc<FirestoreDatabase>>>`, drops them via `clear_database`, and broadcasts lifecycle and mutation `ProjectEvent` notifications over a bounded `tokio::sync::broadcast::Sender<ProjectEvent>` channel (`MAX_PROJECT_EVENT_BACKLOG = 1024`).
- `[database.rs:FirestoreDatabase]`: Validates writable `Value` variants in `[database/validation.rs:validate_write]` (and `[database/commit.rs:FirestoreDatabase::stage_write]`), mutates in-memory collection and document state during `write`, `create_doc`, `update_doc`, `delete_doc`, `delete_prefix`, and `commit`, and broadcasts `Arc<DatabaseEvent>` updates (as well as `ProjectEvent::DocumentsChanged` and `ProjectEvent::DatabaseConfigChanged`) over `tokio::sync::broadcast::Sender` channels (`MAX_EVENT_BACKLOG = 1024`).
- `[listener.rs:Listener::start]`: Spawns a background `tokio::spawn` task that subscribes to database broadcast streams, emits `ListenResponse` messages over a bounded `mpsc::channel(16)`, and automatically reconnects and resets targets when a database is dropped.
- `[utils.rs:unimplemented]`: Logs unsupported feature messages to `stderr` via `eprintln!`.
