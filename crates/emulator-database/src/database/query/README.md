# query

## Overview
Structured query filter representations, `StructuredQuery.findNearest` vector-search specification, and predicate evaluation logic supporting composite (`AND`/`OR`), field comparison/array, and unary (`IS NAN`/`IS NULL`/`IS NOT NAN`/`IS NOT NULL`) filters across Standard and Enterprise editions.

## Interface
- `[filter.rs:Filter]`: `pub enum Filter { Composite(CompositeFilter), Field(FieldFilter), Unary(UnaryFilter) }` with methods `get_inequality_fields`, `sorted_non_name_inequality_fields`, `field_filters`, `eval`, `as_composite`, `as_field`, `as_unary`.
- `[filter.rs:CompositeFilter]`: `pub struct CompositeFilter { pub op: CompositeOperator, pub filters: Vec<Filter> }`
- `[filter.rs:CompositeOperator]`: `pub enum CompositeOperator { And, Or }`
- `[filter.rs:FieldFilter]`: `pub struct FieldFilter { pub field: FieldReference, pub op: FieldOperator, pub value: Value }` (manual bounded `fmt::Debug` printing `array_len` and up to a 3-element `array_prefix` for `ArrayValue` operands)
- `[filter.rs:FieldOperator]`: `pub enum FieldOperator { LessThan, LessThanOrEqual, GreaterThan, GreaterThanOrEqual, Equal, NotEqual, ArrayContains, In, ArrayContainsAny, NotIn }` (`wire_name`, `is_array_operand`, `needs_type_compat`, `is_inequality`)
- `[filter.rs:UnaryFilter]`: `pub struct UnaryFilter { pub field: FieldReference, pub op: UnaryOperator }`
- `[filter.rs:UnaryOperator]`: `pub enum UnaryOperator { IsNan, IsNull, IsNotNan, IsNotNull }` (`is_inequality`)
- `[find_nearest.rs:FindNearest]`: `pub struct FindNearest { pub vector_field: FieldPath, pub query_vector: Vec<f64>, pub distance_measure: DistanceMeasure, pub limit: usize, pub distance_result_field: Option<FieldPath>, pub distance_threshold: Option<f64> }` (`new`, `distance_result_field`, `distance_threshold`, `validate`, `try_from_proto`, bounded `fmt::Debug` logging dimensionality and up to 3 coordinates).

## Invariants
- `[../query.rs:Query::missing_docs_at]`: Evaluates phantom ancestor discovery lock-free over MVCC snapshots under `ReadConsistency::Default` and `ReadConsistency::ReadTime` (checking child collection existence via `Collection::has_doc_at(ts)` and ancestor absence via `db.peek_doc_meta(&name)?.and_then(|meta| meta.read_mvcc_at(ts)).is_none()` without acquiring `LockTable` locks or allocating `DocumentMeta`), while retaining `Collection::has_doc()` and `db.get_doc(&name, self.consistency)` under `ReadConsistency::Transaction` and preserving `after_cursor` reference-order filtering across all modes.
- `[filter.rs:Filter::try_from]`, `[filter.rs:FieldFilter::try_from]`, `[filter.rs:UnaryFilter::try_from]`, `[filter.rs:CompositeOperator::try_from]`, `[filter.rs:FieldOperator::try_from]`, `[filter.rs:UnaryOperator::try_from]`: Reject missing required protobuf subfields (`filter_type`, `field`/`value`, `operand_type`) and `Operator::Unspecified` with `GenericDatabaseError::InvalidArgument`.
- `[filter.rs:CompositeFilter::eval]` & `[filter.rs:FieldFilter::eval]`: `CompositeFilter::eval` short-circuits `And`/`Or` (`And([]) => true`, `Or([]) => false`). `FieldFilter::eval` evaluates all 10 `FieldOperator` variants across editions (returning `bool`). Missing fields evaluate to `false` except for `FieldOperator::NotEqual` and `FieldOperator::NotIn` when `is_enterprise` is `true`. Under Standard Edition (`!is_enterprise`), equality and array membership (`value_matches_eq`, `operand_contains`, `Equal`, `ArrayContains`, `In`, `ArrayContainsAny`) return `false` when matching top-level `null` or `NaN` values, `NotEqual` returns `false` when either side is `null` (while matching `NaN != NaN` on raw filters), and `NotIn` returns `false` whenever the field value is `null` or the operand array contains `null`; under Enterprise Edition, `null == null` and `NaN == NaN` match directly. Ordering operators (`LessThan`, `LessThanOrEqual`, `GreaterThan`, `GreaterThanOrEqual`) require `Value::is_compatible_with` type compatibility (plus non-`null`/non-`NaN` values on Standard Edition).
- `[filter.rs:Filter::sorted_non_name_inequality_fields]`: Sorts and deduplicates non-`__name__` inequality field paths by segment-wise `FieldPath::Ord` (handling escaped dots without temporary string splitting).
- `[filter.rs:UnaryFilter::eval]`: Missing fields evaluate to `false` except for `UnaryOperator::IsNotNan` and `UnaryOperator::IsNotNull` when `is_enterprise` is `true`; `IsNotNan` on `NULL` values evaluates to `false` unless `is_enterprise` is `true`.
- `[find_nearest.rs:FindNearest::validate]` & `[find_nearest.rs:FindNearest::try_from_proto]`: Requires a valid `DistanceMeasure`, a non-reserved `vector_field`, optional non-reserved `distance_result_field`, valid `query_vector` (`1..=2048` non-`NaN` coordinates, returning `FailedPrecondition` on Standard Edition zero-norm `Cosine`, `InvalidArgument` on Enterprise Edition zero-norm `Cosine`, and `InvalidArgument` on both editions when `Cosine` self-distance evaluates to `NaN` such as `Infinity`/overflow), `limit` in `1..=1000`, and non-`NaN` `distance_threshold`, rejecting invalid inputs cleanly. Inside `Query::validate`, all `FieldFilter` and `Cursor` values validate nested `__vector__` sentinel maps via `validate_query_operand_value` (`NaN` rejected on Enterprise Edition only), and `find_nearest` cannot be combined with outer `limit`, `offset > 0`, or cursors; Standard Edition applies the same inequality + `__name__` `order_by` synthesis (`last_dir`, `__name__`-last enforcement, and missing-field exclusion in `matches_prefilters`) and tie-breaks via `order_by_cmp`, whereas Enterprise Edition keeps `order_by` as pre-filters only and tie-breaks via precomputed `sorted_non_name_inequality_fields` `ASC` then segment-wise `__name__ ASC`.

## Side Effects
- Pure in-memory filter evaluation and validation without `stdout`/`stderr` output or database state mutations.
