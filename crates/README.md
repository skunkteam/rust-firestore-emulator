# crates

## Overview
Workspace crates directory containing the modular Rust libraries and verification suites that power the Firestore emulator: in-memory database storage, Wound-Wait transaction locking, and query/pipeline execution, Tonic gRPC and Axum HTTP server interfaces, dynamic tracing and log capture, compiled Google Firestore v1 protobuf definitions, and centralized black-box wire tests.

## Subdirectories & Boundaries
- `emulator-database`: [./emulator-database/README.md](./emulator-database/README.md) - In-memory Cloud Firestore database engine (`FirestoreProject`, `FirestoreDatabase`), MVCC document storage, Wound-Wait and optimistic transactions, structured/aggregation queries, vector search (`findNearest` / distance metrics), Enterprise Edition pipelines, real-time change listeners, and the pure in-memory `.fsemu` binary snapshot export/import subsystem.
- `emulator-grpc`: [./emulator-grpc/README.md](./emulator-grpc/README.md) - Tonic `FirestoreServer` gRPC implementation (`service`) for `google.firestore.v1.Firestore`, stream error wrapping (`error_in_stream`), and request validation macros.
- `emulator-http`: [./emulator-http/README.md](./emulator-http/README.md) - Axum HTTP `RouterBuilder`, `/emulator/v1` REST inspection, clearing, recursive prefix deletion (`DELETE /emulator/v1/{*ref}`), binary `.fsemu` snapshot export/import (`/emulator/v1/export`, `/emulator/v1/import`, compiled regardless of the `ui` Cargo feature), and SSE live invalidation (`/emulator/v1/events`, `/emulator/v1/contention/events`), `/emulator/v1/logging` dynamic log capture routes, `/v1/projects` database configuration and Firestore v1 ProtoJSON REST CRUD/query routes (plus `501` Phase-2 verb stubs), and explicit `/ui/{*path}`, `/lit-html.js`, and root fallback UI serving (disk-first with `FIRESTORE_EMULATOR_UI_DIR` in debug builds, embedded in release).
- `emulator-tests`: [./emulator-tests/README.md](./emulator-tests/README.md) - Single-target `#![cfg(test)]` black-box verification crate exercising `emulator-grpc`, `emulator-http`, `emulator-database`, `emulator-tracing`, and `firestore-emulator` over in-memory Tonic/Axum wire boundaries, `proptest` state-invariants, paused virtual-time contention schedules, and loopback TCP multiplexing.
- `emulator-tracing`: [./emulator-tracing/README.md](./emulator-tracing/README.md) - Idempotent global `tracing_subscriber` initialization (`DefaultTracing::start`) and runtime-filtered in-memory log capture (`Tracing`, `DynamicSubscriber`).
- `googleapis`: [./googleapis/README.md](./googleapis/README.md) - Build-time `tonic-prost-build` protobuf compilation for Google Firestore v1 (with optional `client` feature), Proto3 JSON `serde` (`ser.rs`, `build.rs`), declarative `val!`/`fields!`/`doc!` macros, `vector_ext` `VectorValue` helpers, `cmp_reference_paths`/`cmp_reference_segments`, and Rust domain extensions for `Timestamp`, `TransactionOptions`, `Value`, and `LatLng`.
