# emulator-tracing (`src`)

## Overview
Implements the `emulator-tracing` crate's global `tracing` subscriber initialization and dynamic runtime log-level subscription mechanism. It configures the process-wide `tracing_subscriber` registry and allows callers to dynamically attach and drain filtered in-memory formatted log streams without restarting the global subscriber.

## Interface
- `[lib.rs:DefaultTracing]` — Public struct managing the `reload::Handle<LayerUnion, Registry>` and local/UTC `OffsetTime` formatter.
- `[lib.rs:DefaultTracing::start]` — `pub fn start() -> &'static Self`: Initializes the global `tracing_subscriber` registry with a `reload::Layer<LayerUnion, Registry>` seeded with an `[lib.rs:EnvFilteredLayer]` (`EnvFilter::from_default_env()` + `FmtSpan::NEW | FmtSpan::CLOSE`) and returns a `'static` reference.
- `[lib.rs:Tracing]` — `pub trait Tracing: Send + Sync` providing `fn subscribe(&self, dirs: &str) -> Result<impl DynamicSubscriber + '_, SetLogLevelsError>` (implemented for `DefaultTracing`).
- `[lib.rs:DynamicSubscriber]` — `pub trait DynamicSubscriber: Send` providing `fn drain(&mut self) -> Bytes` to consume formatted log bytes accumulated by a dynamic subscriber.
- `[lib.rs:SetLogLevelsError]` — Public error enum with variants `InvalidDirectives(#[from] metadata_filter::ParseError)` and `ReloadError(#[from] reload::Error)`.
- `[metadata_filter.rs:ParseError]` — Directive parsing error enum (`InvalidDirective(String)`) declared `pub` inside private `mod metadata_filter` (not re-exported by `lib.rs`, exposed through `SetLogLevelsError::InvalidDirectives`).

## Invariants
- `[lib.rs:DefaultTracing::start]` guards initialization with a process-wide `static INSTANCE: OnceLock<DefaultTracing>` so the global default tracing dispatcher (`registry.init()`) is installed at most once per OS process and repeated calls safely return the same `'static DefaultTracing` reference. `[lib.rs:LayerUnion]` composes `[lib.rs:EnvFilteredLayer]` (default `EnvFilter`) and dynamically attached `[lib.rs:DynamicFilteredLayer]` instances with union (`OR`) semantics for `register_callsite`, `enabled`, `event_enabled`, and `max_level_hint`—avoiding both `Vec<BoxedLayer>::enabled`/`event_enabled`'s `.all(...)` cross-layer veto and `tracing_subscriber::filter::Filtered`'s always-`Interest::always()` registration (`tokio-rs/tracing#1629`). Each filtered layer gates all span/event callbacks on its own filter (including `event_enabled`) to prevent cross-subscriber and `RUST_LOG` leakage, explicitly drops `SpanRef` extension guards before invoking inner layers, and dynamic layers use `FmtSpan::NEW` (omitting `FmtSpan::CLOSE`) so `default_layer` remains the sole owner of `tracing_subscriber`'s per-span `Timings` extension when subscribers attach mid-span.
- `[lib.rs:DefaultDynamicSubscriber::drop]` expects the subscriber's boxed layer pointer (`[lib.rs:ptr]`) to remain present in `reload_handle`'s layer vector until dropped, panicking if the layer is missing or reload modification fails.
- `[metadata_filter.rs:Filter::from_str]`, `[metadata_filter.rs:Directive::from_str]`, `[metadata_filter.rs:Directive::matches_target]`, `[metadata_filter.rs:Filter::allows]`, & `[metadata_filter.rs:Filter::max_level]`: `Filter::from_str` splits and trims comma-separated directives while `Directive::from_str` parses a single directive matching either a global level (`trace|debug|info|warn|error|off|[0-5]`, case-insensitive) or `target[=level]` (`target` matching alphanumeric, `_`, `:`, or `-` characters, defaulting to `LevelFilter::TRACE`); `Filter::allows` evaluates all directives matching via `Directive::matches_target`, selects the most specific match (longest `target` length, breaking ties in favor of the last matching directive via `Iterator::max_by_key`), and permits events/spans whose level satisfies `meta.level() <= &dir.level`; `Filter::max_level` returns the highest `LevelFilter` across directives (or `LevelFilter::OFF` when empty) for `Layer::max_level_hint`.

## Side Effects
- `[lib.rs:DefaultTracing::start]` (on first invocation via `OnceLock::get_or_init`) checks the local UTC offset via `UtcOffset::current_local_offset()` (writing a fallback note to `stderr` via `eprintln!` on `IndeterminateOffset`), reads `RUST_LOG` from the environment via `EnvFilter::from_default_env()`, initializes the global `tracing` dispatcher (`registry.init()`), and stores `DefaultTracing` in `INSTANCE`.
- `[lib.rs:Tracing::subscribe]` and `[lib.rs:DefaultDynamicSubscriber::drop]` mutate the active `tracing_subscriber::reload::Layer` vector via `reload_handle.modify(...)` and buffer formatted log output in an in-memory `Arc<Mutex<VecDeque<u8>>>` (`[lib.rs:SharedBuffer]`, capped at `DEFAULT_MAX_BUFFER_BYTES = 16 MiB`, dropping oldest bytes along valid UTF-8 boundaries via `is_utf8_cont_byte` on overflow and recovering from poisoned mutexes via `PoisonError::into_inner`).
