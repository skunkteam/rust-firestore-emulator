# src

## Overview
Core source package for `emulator-http`. Exposes `RouterBuilder` to construct the Axum HTTP `Router` with nested emulator control/SSE, Firestore v1 REST CRUD/Query, and dynamic logging routes, `naersk`-safe embedded/disk UI asset serving, response header layers, and Google Cloud `google.rpc.Status` JSON error responses (`RestError`).

## Interface
- `pub struct RouterBuilder(Router)` (`[lib.rs:RouterBuilder]`, `[routes.rs:RouterBuilder]`): Builder for assembling the emulator's Axum `Router`.
- `pub fn RouterBuilder::new(project: &'static FirestoreProject) -> Self` (`[routes.rs:RouterBuilder::new]`): Creates a `RouterBuilder` nesting `/emulator/v1` and `/v1/projects` bound to `project`.
- `pub fn RouterBuilder::add_dynamic_tracing(self, tracing: &'static impl Tracing) -> Self` (`[routes.rs:RouterBuilder::add_dynamic_tracing]`): Nests the `/emulator/v1/logging` router bound to `tracing`.
- `pub fn RouterBuilder::build(self) -> Router` (`[routes.rs:RouterBuilder::build]`): Finalizes the `Router` with `/ui/{*path}` and `/lit-html.js` asset handlers (under `feature = "ui"`), API-isolated fallback routes, `Cache-Control: no-cache` header overriding, and HTTP tracing middleware.
- `pub(crate) struct RestError`, `pub(crate) struct ApiJson<T>`, `pub(crate) fn parse_json_body`, and `pub(crate) type Result<T, E = RestError>` (`[error.rs:RestError]`, `[error.rs:ApiJson]`, `[error.rs:parse_json_body]`, `[error.rs:Result]`): Internal error and JSON extractor types formatting errors as Google Cloud `google.rpc.Status` JSON envelopes.
- Subdirectories:
  - [routes](./routes/README.md): Axum route handlers for `/emulator/v1`, `/emulator/v1/logging`, and `/v1/projects`.

## Invariants
- `RouterBuilder::new` and `RouterBuilder::add_dynamic_tracing` require `'static` references to `FirestoreProject` and `impl Tracing` (`[routes.rs:RouterBuilder::new]`, `[routes.rs:RouterBuilder::add_dynamic_tracing]`).
- Every response from the built router overrides `Cache-Control` to `"no-cache"` via `SetResponseHeaderLayer::overriding` (`[routes.rs:NO_CACHE]`, `[routes.rs:RouterBuilder::build]`).
- Unmatched routes under `/v1/*` and `/emulator/*` always return `404 NOT_FOUND` JSON error envelopes rather than HTML, regardless of whether `feature = "ui"` is enabled (`[routes.rs:root_fallback]`).
- When Cargo feature `ui` is enabled (`#[cfg(feature = "ui")]`), `/ui/{*path}` serves assets from disk first in debug builds (`FIRESTORE_EMULATOR_UI_DIR` or `CARGO_MANIFEST_DIR/../../ui`) and falls back to compile-time `UI_ASSETS` generated by `build.rs`, injecting `window.EMULATOR_VERSION` into `index.html`; missing `/ui/*` assets return `404 Not Found` (`[routes.rs:serve_ui_asset]`).
- `RestError` maps `GenericDatabaseError` variants to `(StatusCode, grpc_status)`: `InvalidArgument` / `InvalidReference` -> `(400, "INVALID_ARGUMENT")`, `FailedPrecondition` -> `(400, "FAILED_PRECONDITION")`, `AlreadyExists` -> `(409, "ALREADY_EXISTS")`, `Aborted` -> `(409, "ABORTED")`, `Cancelled` -> `(499, "CANCELLED")`, `NotImplemented` -> `(501, "UNIMPLEMENTED")`, and `Internal` -> `(500, "INTERNAL")` (`[error.rs:RestError]`).

## Side Effects
- Routes incoming HTTP requests to handlers in [routes](./routes/README.md) that read and mutate `FirestoreProject` and `Tracing` state, and reads `ui/` files from disk in debug builds (`[routes.rs:RouterBuilder]`, `[routes.rs:serve_ui_asset]`).
- Emits HTTP trace events via `tower_http::trace::TraceLayer::new_for_http()` and debug logs on JSON deserialization or REST error responses (`[routes.rs:RouterBuilder::build]`, `[error.rs:RestError]`).
