# UI (`ui`)

## Overview
Zero-build, multi-file ES-module web application for inspecting, creating, editing, deleting, and querying Cloud Firestore Emulator state. Served by `crates/emulator-http` when its opt-in `ui` Cargo feature is enabled (`default = []` on `emulator-http`; enabled by default via `default = ["ui"]` on the root `firestore-emulator` crate — live from disk in debug builds and embedded into the binary via `crates/emulator-http/build.rs` in release builds), it communicates with the core Firestore v1 ProtoJSON REST API (`/v1/projects/{project_id}/databases/{database_id}/...`) and the emulator control plane (`/emulator/v1/...`, including SSE live invalidations on `/emulator/v1/events`) and renders declaratively using vendored `lit-html@3.1.2`.

## Subdirectories
- `components`: [./components/README.md](./components/README.md) - Declarative UI view components and pure domain modules for Miller-column collection/document navigation (`explorer.js`), hybrid structured field-tree and Raw ProtoJSON document editing (`editor.js`), pure query/aggregation models and Raw JSON validation (`query-model.js`), the 2x2 Documents/Aggregations structured query runner (`query.js`), the pure `lit-html` WAI-ARIA 1.2 combobox (`combobox.js`), the DB-scoped standard-REST autosuggestion engine (`query-suggestions.js`), the live lock contention visualizer (`contention.js`), and modal dialogs (`modals.js`).
- `tests`: Zero-dependency `node:test` unit and regression suite (`*.test.mjs`) with a shared DOM/`fetch`/`EventSource`/`lit-html` harness (`helpers/dom-harness.mjs`) and standalone ESLint config (`eslint.config.mjs`), excluded from both embedded release assets (`crates/emulator-http/build.rs`) and debug disk serving (`crates/emulator-http/src/routes.rs:serve_ui_asset`).

## Invariants
- **Zero-Build ES Modules**: Every `.js` module uses browser-native relative ES module imports (`./...` or `../...`) with `// @ts-check` JSDoc annotations and requires zero bundling or transpilation steps.
- **Lossless `i64` vs. `f64` Fidelity (`[values.js:validateInteger64]`, `[values.js:validateDouble]`)**: `integerValue` strings are validated strictly via `BigInt` against `[-9223372036854775808n, 9223372036854775807n]` without `Number` coercion, while `doubleValue` preserves `NaN`, `Infinity`, `-Infinity`, and `-0.0`.
- **Client-Supplied Document IDs (`[components/modals.js:renderModal]`, `[values.js:generateAutoId]`)**: Creating a document via the modal's inner `submit` handler always supplies a non-empty `documentId` query parameter (auto-filling with `generateAutoId()` if left blank in the modal).
- **Dirty-Editor SSE Protection (`[app.js:loadDocumentLevel]`, `[components/editor.js:syncSessionWithDocument]`)**: When a session is clean (`isDirty === false`), `syncSessionWithDocument` replaces session state directly; when `isDirty === true`, `loadDocumentLevel` preserves local edits and records incoming `externalDoc` updates or external 404 deletions (`deletedExternally = true`) to surface a non-destructive reload/keep banner.
- **Cleared-DB SSE Preemption & Epoch Isolation (`[app.js:applySyncSseBatch]`, `[app.js:applyAsyncSseRefresh]`, `[state.js:getDbSignal]`, `[components/query-suggestions.js:resetQuerySuggestionStore]`)**: `applySyncSseBatch` executes synchronously on incoming SSE batches, calling `nextDbListSeq()` on `database_cleared` to discard any in-flight pre-clear `GET /emulator/v1` response, resetting `state.querySuggestions`, rotating DB cancellation signals (`getDbSignal()`), aborting active queries/Explorer reads, and preventing `applyAsyncSseRefresh` from issuing post-notification `/v1` requests against a cleared database while still allowing project-wide `listDatabases` updates across active-DB epoch changes when `!state.ssePaused`; `documents_changed` / `resync` / unpause mark suggestion caches stale lazily without firing background re-crawls.

## Side Effects
- `[app.js]`: Mutates DOM subtrees in `#topbar`, `#workspace`, `#modal-root`, and `#toast-root`, reconciles/closes inactive comboboxes via `[components/combobox.js:reconcileComboboxUi]`, updates empty `.wait-elapsed[data-wait-base-ms]` text/attributes on render and `1000ms` waiter ticks without Lit re-rendering, registers `window` `popstate` and `document` `visibilitychange` listeners, and initiates gated SSE subscriptions via `[api.js:connectEventStream]` and `[api.js:connectContentionEvents]`.
- `[components/modals.js]`: Creates and revokes temporary blob object URLs on snapshot export (`URL.createObjectURL` / `URL.revokeObjectURL` deferred `60_000ms` inside `try ... finally` so cleanup runs even if click throws) and tracks/resets `<input type="file">` (`importFileInputEl`) for repeated `.fsemu` selection.
- `[router.js]`: Updates browser history via `window.history.pushState` / `window.history.replaceState` (`syncBrowserUrl`).
- `[state.js]`: Schedules toast auto-dismissal timers via `setTimeout` (`pushToast`) and manages `dbAbortController` / `activeQueryAbortController` lifecycles.
- `[api.js]`: Issues `fetch` HTTP `GET`, `POST`, `PATCH`, and `DELETE` requests to `/v1/projects/...` and `/emulator/v1/...` (including binary `.fsemu` snapshot transfers on `/emulator/v1/export` and `/emulator/v1/import`), and maintains `EventSource` connections to `/emulator/v1/events` (`connectEventStream`) and `/emulator/v1/contention/events` (`connectContentionEvents`, active only while the Contention view is open, visible, and unpaused).
- `[lit-html.js]`: Registers a `"lit-html"` `trustedTypes` policy when supported by the browser and appends `"3.1.2"` to `globalThis.litHtmlVersions`.
