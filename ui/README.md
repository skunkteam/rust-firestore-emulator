# UI (`ui`)

## Overview
Zero-build, multi-file ES-module web application for inspecting, creating, editing, deleting, and querying Cloud Firestore Emulator state. Served by `crates/emulator-http` when its opt-in `ui` Cargo feature is enabled (`default = []` on `emulator-http`; enabled by default via `default = ["ui"]` on the root `firestore-emulator` crate — live from disk in debug builds and embedded into the binary via `crates/emulator-http/build.rs` in release builds), it communicates with the core Firestore v1 ProtoJSON REST API (`/v1/projects/{project_id}/databases/{database_id}/...`) and the emulator control plane (`/emulator/v1/...`, including SSE live invalidations on `/emulator/v1/events`) and renders declaratively using vendored `lit-html@3.1.2`.

## Subdirectories
- `components`: [./components/README.md](./components/README.md) - Declarative UI view components for Miller-column collection/document navigation (`explorer.js`), the hybrid structured field-tree and Raw ProtoJSON document editor (`editor.js`), the structured query runner (`query.js`), and the modal dialogs (`modals.js`).

## Interface
- `[index.html]`: Minimal HTML shell mounting `<header id="topbar">`, `<main id="workspace">`, `<div id="modal-root">`, `<div id="toast-root">`, `/ui/styles.css`, and `<script type="module" src="/ui/app.js">`.
- `[styles.css]`: CSS custom properties (light theme CSS tokens), responsive topbar, horizontal Miller-column layout, type badges, hybrid field-tree / Raw ProtoJSON editor styles, query builder layout, modal dialogs, and toast notifications.
- `[app.js]`: Top-level SPA orchestration controller managing database discovery and bootstrap (`+ Open / Create Database`), inline `STANDARD`/`ENTERPRISE` and `PESSIMISTIC`/`OPTIMISTIC` toggles, debounced SSE live invalidation (`Pause Live Updates` + dirty-editor protection), `popstate` listener wiring, `lit-html` root rendering, and exported/re-exported `state`, `parseBrowserRoute`, `selectDatabase`, `hydrateVisiblePath`, `loadCollectionColumn`, `loadDocumentLevel`, `handleSseBatch`, `saveDocumentFromInspector`, `toggleDatabaseSetting`, `openCreateDocumentModal`, `renderWorkspace`, `renderModal`, `init`, and `executeCurrentQuery` (formatting `ApiError` banners as `` `[${err.code} ${err.status}] ${err.message}` ``).

- `[router.js:parseBrowserRoute]` / `[router.js:syncBrowserUrl]` / `[router.js:getActiveRootPath]` / `[router.js:isValidPathSegment]` / `[router.js:relativeSegments]` / `[router.js:startsWithSegments]`: Pure URL `pushState`/`replaceState` routing and Firestore resource path segment validation helpers (`/projects/{project}/databases/{database}/documents/...`).
- `[api.js:ApiError]`: Structured HTTP client error capturing HTTP status code and Google Cloud `google.rpc.Status` fields (`code`, `status`, `message`).
- `[api.js:encodeResourcePath]` / `[api.js:parseRootRef]`: Resource path segment encoder and root reference parser (`projects/{p}/databases/{d}/documents`).
- `[api.js:listDatabases]` / `[api.js:getDatabase]` / `[api.js:patchDatabase]` / `[api.js:clearDatabase]`: Emulator database discovery, metadata inspection, edition/concurrency patching, and database clearing helpers.
- `[api.js:listCollectionIds]` / `[api.js:listDocuments]` / `[api.js:getDocument]` / `[api.js:createDocument]` / `[api.js:updateDocument]` / `[api.js:deleteDocument]` / `[api.js:deleteCollection]` / `[api.js:runQuery]`: Firestore v1 ProtoJSON REST CRUD, recursive prefix deletion, and structured query helpers.
- `[api.js:connectEventStream]`: Connects an `EventSource` to `/emulator/v1/events`, coalescing `change` and `resync` events over a `150ms` trailing debounce window.
- `[values.js:VALUE_TYPES]` / `[values.js:getValueType]` / `[values.js:createDefaultValue]` / `[values.js:formatDoubleInput]` / `[values.js:formatValuePreview]` / `[values.js:setFieldProperty]`: Type descriptors, discriminators, default constructors, double input formatting (`-0.0` preservation), compact preview formatters for all 11 storable Firestore ProtoJSON `Value` types, and safe field assignment helpers.
- `[values.js:isVectorMapValue]` / `[values.js:formatVectorSummary]` / `[values.js:firestoreValueEquals]`: Cloud Firestore vector sentinel (`__vector__`) detection, compact dimension/head summary formatting, and structural ProtoJSON value equality (using `Object.is` for doubles and comparing map fields independent of key order).
- `[values.js:validateInteger64]` / `[values.js:validateDouble]` / `[values.js:validateTimestamp]` / `[values.js:validateGeoPoint]` / `[values.js:encodeBytes]` / `[values.js:decodeBytes]` / `[values.js:normalizeReference]` / `[values.js:escapeFieldPathSegment]` / `[values.js:findUnsafeUnquotedInteger]` / `[values.js:validateRawProtoJsonFields]` / `[values.js:normalizeProtoValue]` / `[values.js:stringifyProtoJson]`: Lossless client-side validators, normalizers, and encoders (`BigInt`-checked signed 64-bit integers, pre-`JSON.parse` detection of unquoted `|n| >= 2^53` integers outside `doubleValue` properties, IEEE-754 doubles rejecting non-finite numeric `doubleValue` overflows in `normalizeProtoValue` while supporting `"NaN"`/`"Infinity"`/`"-Infinity"` strings and `-0.0`, RFC 3339 timestamps, Base64/UTF-8/hex bytes, resource references, field-mask escaping, recursive raw ProtoJSON validation, and `-0.0`-preserving JSON serialization).
- `[values.js:generateAutoId]`: Generates a uniform, bias-free 20-character alphanumeric Firestore document ID via `crypto.getRandomValues` rejection sampling.
- `[lit-html.js]` / `[lit-html.d.ts]`: Vendored `lit-html@3.1.2` ES module (`html`, `svg`, `render`, `noChange`, `nothing`, `_$LH`, `default`) and local ambient TypeScript declarations (`TemplateResult`, `RenderOptions`) for `tsc --checkJs --strict`.

## Invariants
- **Zero-Build ES Modules**: Every `.js` module uses browser-native relative ES module imports (`./...` or `../...`) with `// @ts-check` JSDoc annotations and requires zero bundling or transpilation steps.
- **Lossless `i64` vs. `f64` Fidelity (`[values.js:validateInteger64]`, `[values.js:validateDouble]`)**: `integerValue` strings are validated strictly via `BigInt` against `[-9223372036854775808n, 9223372036854775807n]` without `Number` coercion, while `doubleValue` preserves `NaN`, `Infinity`, `-Infinity`, and `-0.0`.
- **Client-Supplied Document IDs (`[components/modals.js:renderModal]`, `[values.js:generateAutoId]`)**: Creating a document via the modal's inner `submit` handler always supplies a non-empty `documentId` query parameter (auto-filling with `generateAutoId()` if left blank in the modal).
- **Dirty-Editor SSE Protection (`[app.js:loadDocumentLevel]`, `[components/editor.js:syncSessionWithDocument]`)**: When a session is clean (`isDirty === false`), `syncSessionWithDocument` replaces session state directly; when `isDirty === true`, `loadDocumentLevel` preserves local edits and records incoming `externalDoc` updates or external 404 deletions (`deletedExternally = true`) to surface a non-destructive reload/keep banner.

## Side Effects
- `[app.js]`: Mutates DOM subtrees in `#topbar`, `#workspace`, `#modal-root`, and `#toast-root`, registers a `window` `popstate` listener, and initiates SSE subscriptions via `[api.js:connectEventStream]`.
- `[router.js]`: Updates browser history via `window.history.pushState` / `window.history.replaceState` (`syncBrowserUrl`).
- `[state.js]`: Schedules toast auto-dismissal timers via `setTimeout` (`pushToast`).
- `[api.js]`: Issues `fetch` HTTP `GET`, `POST`, `PATCH`, and `DELETE` requests to `/v1/projects/...` and `/emulator/v1/...`, and maintains a long-lived `EventSource` connection to `/emulator/v1/events` (`connectEventStream`).
- `[lit-html.js]`: Registers a `"lit-html"` `trustedTypes` policy when supported by the browser and appends `"3.1.2"` to `globalThis.litHtmlVersions`.
