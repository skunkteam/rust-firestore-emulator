# UI Components (`ui/components`)

## Overview
`lit-html` view templates and pure domain/controller modules powering the Web UI: horizontal Miller-column exploration (`explorer.js`), hybrid field-tree / Raw ProtoJSON document editing (`editor.js`), pure DOM-free `StructuredQuery` & `StructuredAggregationQuery` state/builders/Raw JSON validation (`query-model.js`), the 2x2 Query Runner view (`query.js`), reusable WAI-ARIA 1.2 combobox rendering (`combobox.js`), DB-scoped standard-REST autosuggestions (`query-suggestions.js`), live lock contention visualization (`contention.js`), and modal dialogs (`modals.js`).

## Interface
- `[explorer.js:renderExplorer]`: Renders arbitrary-depth horizontal Miller columns (`Root Collections` -> `Documents` -> `Document Inspector & Subcollections` -> nested levels), including phantom ancestor document indicators (`showMissing=true`), collection filters, pagination (`Load more`), and collection/document action triggers.
- `[editor.js:createEditorSession]` / `[editor.js:syncSessionWithDocument]` / `[editor.js:fieldsToDraftNodes]` / `[editor.js:draftNodesToFields]` / `[editor.js:extractSessionFields]` / `[editor.js:computeChangedFieldMask]` / `[editor.js:renderHybridEditor]`: Manages bidirectional conversion and validation between recursive `DraftNode` trees and Raw ProtoJSON `{"fields": ...}` text, computes `updateMask.fieldPaths` diffs (including deleted fields), and renders both the Structured Tree View and Raw ProtoJSON editor tabs.
- `[query-model.js:FILTER_OPERATORS]` / `[query-model.js:SCALAR_FILTER_TYPES]` / `[query-model.js:SCALAR_FILTER_TYPE_SET]` / `[query-model.js:UNSUPPORTED_QUERY_ENVELOPE_KEYS]` / `[query-model.js:STANDARD_MAX_AGGREGATIONS]` / `[query-model.js:ENTERPRISE_MAX_AGGREGATIONS]` / `[query-model.js:createFilterRow]` / `[query-model.js:createOrderRow]` / `[query-model.js:createAggregationRow]` / `[query-model.js:createQueryRunnerState]` / `[query-model.js:isUntouchedDefaultQueryState]` / `[query-model.js:applyFilterAutoType]` / `[query-model.js:transitionFilterOperator]` / `[query-model.js:buildScalarFilterValue]` / `[query-model.js:buildStructuredQueryFromVisual]` / `[query-model.js:buildAggregationQueryFromVisual]` / `[query-model.js:formatAggProvenanceNote]` / `[query-model.js:parseRawQueryPayload]` / `[query-model.js:extractAggProvenance]`: Pure, `lit-html`-free, DOM-free domain module managing `QueryRunnerState` (`QueryFilterRow`, `QueryOrderRow`, `QueryAggregationRow`), visual query/aggregation compilation (all 14 filter operators, edition-aware `1..=5` Standard vs. `1..=64` Enterprise aggregations, non-clobbering `applyFilterAutoType`, boolean/array `transitionFilterOperator`), provenance formatting, and lossless Raw JSON envelope validation & unwrapping.
- `[query.js:renderQueryRunner]` (re-exporting `createFilterRow`, `createQueryRunnerState`, `buildStructuredQueryFromVisual`, `buildAggregationQueryFromVisual`, `transitionFilterOperator`, `parseRawQueryPayload`, `extractAggProvenance`): Renders the 2x2 (`Documents`/`Aggregations` x `Visual`/`Raw JSON`) Query Runner using `query-model.js` builders, `query-suggestions.js` read-side selectors, a shared field combobox across `Where`, `Order By`, and `SUM`/`AVG`, `topObstructionSelector: "#topbar"` / `clipContainerSelector: ".query-builder-pane"` clipping bounds, `onAbortQueryRun` on `queryKind` switches, and lossless Document / typed Aggregation result cards.
- `[combobox.js:createComboboxUiState]` / `[combobox.js:closeActiveCombobox]` / `[combobox.js:reconcileComboboxUi]` / `[combobox.js:renderCombobox]`: Pure `lit-html` WAI-ARIA 1.2 combobox (`ComboboxUiState`, `ComboboxItem`, `ComboboxRect`, `RectLike`, `ElementLike`) with zero `HTMLElement` / `customElements` references and per-member DOM guards, supporting case-insensitive filtering over `value`/`label`/`matchText`, `id=${id}-popup` (`tabindex="-1"`) with `<ul role="listbox" aria-label=... ?hidden=${filteredItems.length === 0}>`, IME `e.isComposing` guards, `@mousedown` popup pointer-down/release focus recovery, `@blur` / `@focusout` / `selectItem` / popup `Escape`/`Tab`/`ArrowDown`/`ArrowUp`/`Enter` focus management, native `Home`/`End` caret movement, viewport-clamped `popupLeft`/`popupWidth`/`popupBottom`/`maxListboxHeight`, rect-equality scroll/resize no-op guards, and optional `topObstructionSelector`/`clipContainerSelector` dismissal.
- `[query-suggestions.js:formatSuggestionFooter]` / `[query-suggestions.js:parseNormalizedParentSubpath]` / `[query-suggestions.js:createQuerySuggestionStore]` / `[query-suggestions.js:resetQuerySuggestionStore]` / `[query-suggestions.js:markSuggestionsStale]` / `[query-suggestions.js:getParentSubpathSuggestions]` / `[query-suggestions.js:getCollectionIdSuggestions]` / `[query-suggestions.js:getFieldScopeEntry]` / `[query-suggestions.js:ensureSubcollections]` / `[query-suggestions.js:ensureParentSubpathSuggestions]` / `[query-suggestions.js:ensureCollectionGroups]` / `[query-suggestions.js:ensureFieldSuggestions]`: DB-scoped standard-REST autosuggestion store (`SuggestionContext`, `SuggestionCacheEntry`, `FieldHint`, `FieldScopeEntry`, `QuerySuggestionStore`) managing 4 single-owner caches (`subcollectionsByParent`, `docIdsByCollection`, `collectionGroupsByParent`, JSON 3-tuple keyed `fieldsByScope`), read-side selectors, `epoch`, `inflight` promise deduplication, and `invalidationSeq` concurrency tracking.
- `[contention.js:createContentionState]` / `[contention.js:formatWaitDuration]` / `[contention.js:getDisplayedContentionDatabases]` / `[contention.js:hasContentionWaiters]` / `[contention.js:updateWaiterElapsedDom]` / `[contention.js:renderContention]`: Renders the Contention Visualizer workspace (`woundsTotal`, `timeoutsTotal`, `upgradeAbortsTotal`, `writeBatchRetriesTotal`, scope selector + `Clear history`, truncation banners, active writers/readers/ordered waiter queues with empty `.wait-elapsed[data-wait-base-ms][data-wait-ms][data-wait-label]` anchors, recent events feed with wounder attribution, and clickable document links) plus DOM-only waiter elapsed duration updates.
- `[modals.js:renderModal]` / `[modals.js:handleModalKeydown]` / `[modals.js:getModalFocusableElements]`: Renders active modal dialogs (`open_db`, `create_doc`, `delete_doc`, `delete_col`, `clear_db`) with `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, unique `for`/`id` field associations, safe `mousedown` + `click` backdrop dismissal, guarded `Escape`/`Tab` focus trapping, and form validation; calls `../api.js`, `../state.js`, and `../router.js` directly while delegating database selection, path hydration, list refresh, toast notifications, and re-rendering via `ModalCallbacks`.

## Invariants
- `[editor.js:renderHybridEditor]`: Inside the inner mode-switch handler, switching from Raw ProtoJSON back to Structured Tree re-validates `validateRawProtoJsonFields(session.rawText)` so invalid JSON cannot corrupt the structured `DraftNode` tree, and switching from Structured to Raw is blocked when `draftNodesToFields` fails.
- `[editor.js:fieldsToDraftNodes]` / `[editor.js:renderHybridEditor]`: `__vector__` sentinel maps (verified via `[../values.js:isVectorMapValue]`) render as collapsed read-only `'vector'` rows (`vec` badge + `[../values.js:formatVectorSummary]` + remove `✕` button, without a type dropdown or nested tree) and pass their untouched `rawVectorValue` from `cleanDoc` through verbatim on save (preserving untouched `-0.0` coordinates and dirty state across Structured <-> Raw ProtoJSON mode switches).
- `[editor.js:computeChangedFieldMask]`: In structured mode, diffs `cleanDoc.fields` against draft fields structurally via `[../values.js:firestoreValueEquals]` rather than `JSON.stringify` (avoiding false positives from map key ordering or `-0` normalization while keeping untouched vector fields out of `updateMask`); in raw mode, dirty state compares trimmed raw text against `cleanJson`.
- `[editor.js:draftNodesToFields]` / `[editor.js:renderHybridEditor]`: Sibling field keys inside any `Document.fields` or `mapValue.fields` object must be non-empty and unique before saving or syncing to ProtoJSON. Validation tracks key errors and value errors separately per node so empty/duplicate key errors apply `.input-error` to `.field-key-input` while value errors apply `.input-error` to the value control without overwriting each other, and rejected UTF-8 conversions on non-UTF-8 bytes surface an inline `bytesModeError` without dirtying a clean session.
- `[query-model.js:FILTER_OPERATORS]` / `[query-model.js:buildStructuredQueryFromVisual]` / `[query-model.js:transitionFilterOperator]`: All 14 `StructuredQuery` operators supported by `crates/emulator-database/src/database/query/filter.rs` are exposed, with `IN`, `ARRAY_CONTAINS_ANY`, and `NOT_IN` sharing `kind: "array"`. Array parsing checks `[../values.js:findUnsafeUnquotedInteger]` and `[../values.js:findNonFiniteNumber]`, validates explicit ProtoJSON entries via `[../values.js:normalizeProtoValue]`, encodes non-`-0` `Number.isSafeInteger` primitives as `integerValue` strings, encodes `-0`/floats as `doubleValue`, and rejects nested JS arrays. `transitionFilterOperator` initializes `"[]"` on array entry, resets unedited `"[]"` whenever entering a scalar operator (including across unary hops such as `IN` -> `IS_NULL` -> `EQUAL`), runs `applyFilterAutoType`, and normalizes non-`"true"`/`"false"` scalar `booleanValue` text to `"true"` regardless of prior operator kind; `buildScalarFilterValue` treats `booleanValue` as `f.valueText.trim() !== "false"` to match `<select>`.
- `[query-model.js:buildAggregationQueryFromVisual]` / `[query-model.js:parseRawQueryPayload]`: Enforces edition-aware aggregation limits (Standard `1..=5` vs. Enterprise `1..=64`; `COUNT` clears/disables `fieldPath`; `SUM`/`AVG` require `fieldPath`; blank aliases omit `alias` with `field_1`..`field_N` uniqueness; explicit aliases reject `[../values.js:isReservedName]` on Standard only and `> 1500` UTF-8 bytes on both). `parseRawQueryPayload` checks `[../values.js:findUnsafeUnquotedInteger]` and `[../values.js:findNonFiniteNumber]`; wrapped payloads accept canonical `null` for `explainOptions`, `newTransaction`, `requestOptions`, `readTime`, and `transaction` and accept `parent` when `null`, `""`, or equal to `expectedParentPath` (rejecting non-`null` unsupported envelope keys, mismatched/non-string `parent`, and any extra keys); unwrapped payloads allow canonical `null` `UNSUPPORTED_QUERY_ENVELOPE_KEYS` (stripping them from returned payloads) and reject non-`null` values.
- `[combobox.js:renderCombobox]` / `[combobox.js:reconcileComboboxUi]`: Pure `lit-html` templates with zero `HTMLElement` / `customElements` dependencies and per-member browser-API guards, maintaining strict `<ul role="listbox" aria-label=... ?hidden=${filteredItems.length === 0}>` -> `<li role="option">` child purity, viewport-clamped `popupLeft`/`popupWidth`/`popupBottom`/`maxListboxHeight`, `flipUp` positioning, IME `e.isComposing` keydown guards, popup `@mousedown` pointer-down tracking with `<input>` refocus on release / `selectItem` / popup `Escape`/`Tab`/`ArrowDown`/`ArrowUp` (and `@blur`/`@focusout` focus retention), native `Home`/`End` input behavior, and deterministic cleanup of both capture-phase `scroll`/`resize` listeners and temporary pointer-release listeners via `uiState.cleanup` / `closeActiveCombobox`.
- `[query-suggestions.js:createQuerySuggestionStore]` / `[query-suggestions.js:markSuggestionsStale]`: Uses standard Firestore v1 REST endpoints only, deduplicates concurrent non-`force` loads via `store.inflight`, aborts prior key controllers on `force` while chaining same-epoch aborted callers to any replacement `store.inflight` promise, preserves in-flight invalidations (`invalidationSeq`) as `stale: true` on resolution (and propagates `Boolean(subEntry?.stale)` in `ensureCollectionGroups`), checks `!signal.aborted && reqEpoch === store.epoch` before cache writes, handles transient non-abort errors by setting `loading = false, stale = true` and evicting unpopulated initial placeholders (`unpopulatedPlaceholders`) while preserving last-known items on existing entries, keys `fieldsByScope` via `JSON.stringify([normParent, colId, allDescendants])`, and marks matching caches stale lazily on exact resource segment boundaries.
- `[contention.js:renderContention]` / `[contention.js:updateWaiterElapsedDom]`: `.wait-elapsed` spans are rendered empty by `lit-html` (no `ChildPart` comment anchors) and have their `textContent` owned solely by `updateWaiterElapsedDom` (callers must invoke it immediately after rendering and on waiter ticks, falling back to `data-wait-label` when `lastFetchedAtMs === null`). When `snapshot === null && !loading && error`, summary cards render `"—"` and `.contention-body` renders an explicit error + `Retry` control.

## Side Effects
- `explorer.js`, `editor.js`, `query.js`, and `contention.js`: Pure DOM template construction and in-memory state updates (`updateWaiterElapsedDom` mutates `[data-wait-base-ms]` element text/attributes; `query.js` invokes `query-suggestions.js` loaders and `reconcileComboboxUi` when `suggestions` is provided); query execution and Explorer I/O delegate upward to callbacks in `[../app.js]`. `query-model.js` has zero side effects.
- `combobox.js`: Registers and cleans up `window` capture-phase `scroll`/`resize` listeners and temporary popup pointer-release listeners (`mouseup`, `pointerup`, `mousemove`, `blur`, `mousedown`) via `uiState.cleanup` / `closeActiveCombobox`, refocuses `<input>` on pointer release, `selectItem`, and popup `Escape`/`Tab`/`ArrowDown`/`ArrowUp` (and non-button `Enter` close), and calls `scrollIntoView` inside `requestAnimationFrame`.
- `query-suggestions.js`: Issues `AbortSignal`-scoped standard Firestore v1 REST `fetch` calls via `[../api.js]` (`listCollectionIds`, `listDocuments`, `runQuery`) and caches results on `QuerySuggestionStore`.
- `modals.js`: Mutates `state.modal` / `state.segments` / `state.rootCollections` / `state.databases`, updates epochs, sequences, and caches via `[../state.js]`, calls Firestore/Emulator APIs via `[../api.js]`, updates history via `[../router.js:syncBrowserUrl]`, and delegates database selection/hydration/list refresh/toast/rendering to `ModalCallbacks` in `[../app.js]`.
