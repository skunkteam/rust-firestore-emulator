# Conformance Test Utilities (`test-suite/tests/utils`)

## Overview

Shared TypeScript harness utilities for the Cloud Firestore conformance test suite (`test-suite/tests`). Selects the active target backend (`CLOUD FIRESTORE`, `RUST EMULATOR`, or `JAVA EMULATOR`) from environment variables, provisions isolated test collection paths and database editions (`standardEdition`, `enterpriseEdition`, `enterpriseEditionPessimistic`), attaches 1-hour `ttl` fallback timestamps to written test documents, and provides deterministic interleaving primitives (`ConcurrentTest`) for multi-client concurrency and locking assertions.

## Interface

- `[index.ts]`: Barrel module re-exporting `* from './common'`, `* from './concurrent'`, and named symbols (`connection`, `editions`, `enterpriseEdition`, `enterpriseEditionPessimistic`, `notImplementedInJava`, `notImplementedInRust`, `readData`, `readDataRef`, `standardEdition`, `writeData`) from `./firestore`.
- `[firestore.ts:connection]`: `'RUST EMULATOR' | 'JAVA EMULATOR' | 'CLOUD FIRESTORE'` — resolves the active backend from `process.env.FIRESTORE_EMULATOR_HOST` and `process.env.RUST_EMULATOR`.
- `[firestore.ts:notImplementedInRust]` & `[firestore.ts:notImplementedInJava]`: Conditional `[] | undefined` skip guards used with Jest parameterized suites (`describe.each`), direct boolean short-circuits (`notImplementedInJava || test.concurrent(...)`, `notImplementedInRust || describe(...)`), and ternary branches to skip cases unsupported by a specific emulator while still running them against Cloud Firestore.
- `[firestore.ts:standardEdition]`, `[firestore.ts:enterpriseEdition]`, `[firestore.ts:enterpriseEditionPessimistic]`, `[firestore.ts:editions]`: Edition descriptors binding a `@google-cloud/firestore` `Firestore` client, isolated `CollectionReference` (`tests/<auto-id>/collection`), `description` string, `enterprise` boolean, and `concurrencyMode` (`'pessimistic' | 'optimistic'`).
- `[firestore.ts:writeData]`, `[firestore.ts:readData]`, `[firestore.ts:readDataRef]`: Document fixture helpers that inject a 1-hour `ttl` `Timestamp` field on writes and assert/strip `ttl` when reading back document snapshots.
- `[concurrent.ts:ConcurrentTest]`: Deterministic concurrency coordinator (`new ConcurrentTest({ timeout = 8_000 } = {})`) exposing `log: string[]`, `lastEvent$`, `processName: AsyncLocalStorage<string>`, `event(what: string)`, `when(...what: string[]): Promise<void>`, and `run(...processes: Array<() => Promise<unknown>>): Promise<void>`.
- `[common.ts:isDefined]` & `[common.ts:expectToBeOrdered]`: Non-nullish type guard (`inp != null`) and UTF-16 lexicographic sort-order assertion helper (`expect(inp).toEqual(inp.slice().sort())`).
- `[common.ts:expectCloudLimitationCanary]`: Awaits `Promise.resolve().then(fn)` and asserts `err?.code === expectedCode` (default `3`), throwing a canary alert on `CLOUD FIRESTORE` if an expected cloud limitation unexpectedly succeeds.
- `[common.ts:RawProtoValue]`, `[common.ts:RawDocument]`, `[common.ts:RawRunQueryRequest]`, `[common.ts:RawRunQueryResponseChunk]`: Structural raw protobuf payload types for GAPIC `RunQuery` requests/chunks (including `referenceValue` support).
- `[common.ts:normalizeStreamError]`, `[common.ts:callRawUnaryRpc]` & `[common.ts:callRawStreamRpc]`: Typed wrappers around `@google-cloud/firestore`'s internal GAPIC `request` / `requestStream` transport (`initializeIfNeeded`, auth headers, and `x-goog-request-params` database routing) for testing wire-level protobuf payloads that the typed SDK rejects client-side; `normalizeStreamError` returns `Error` instances unchanged and wraps non-`Error` objects via `Object.assign(new Error(msg, { cause: err }), err)` preserving `.code`, `.details`, `.metadata`, `name`, and `stack`; `callRawStreamRpc` invokes `requestStream` with `bidirectional = false` (server-streaming RPCs only), wraps `onChunk?.(typed)` in `try/catch`, rejects premature `'close'` events via `setImmediate` when neither `stream.errored` nor `stream.readableEnded` holds, and keeps `'error'` listeners attached for the lifetime of the stream.
- `[common.ts:toRunQueryProto]`, `[common.ts:rawRunQuery]`, `[common.ts:expectRpcCode]`: Extracts a typed `Query | VectorQuery` to a raw `RunQueryRequest`, streams raw `RunQuery` responses with automatic `CLOUD FIRESTORE` `newTransaction` rollback cleanup, and asserts expected gRPC error status codes with clear diagnostic labels.

## Invariants

- **Backend Target Resolution (`[firestore.ts:connection]`)**: When `FIRESTORE_EMULATOR_HOST` is unset or empty, `connection` always resolves to `'CLOUD FIRESTORE'` regardless of `RUST_EMULATOR`; when `FIRESTORE_EMULATOR_HOST` is set, `RUST_EMULATOR` selects `'RUST EMULATOR'` and its absence selects `'JAVA EMULATOR'`.
- **Edition Filtering on Java Emulator (`[firestore.ts:editions]`, `[firestore.ts:notImplementedInJava]`)**: `editions` includes `enterpriseEdition` (`databaseId: 'enterprise'`, optimistic concurrency) and `enterpriseEditionPessimistic` (`databaseId: 'enterprise-pessimistic'`, pessimistic concurrency) alongside `standardEdition` unless `connection === 'JAVA EMULATOR'`, in which case only `standardEdition` is included.
- **Rust Emulator Edition Provisioning (`[firestore.ts:beforeAll]`)**: When `connection === 'RUST EMULATOR'`, every test file importing `./utils` configures each database in `editions` via `PATCH http://${FIRESTORE_EMULATOR_HOST}/v1/projects/firestore-test-406503/databases/${databaseId}` with `{ databaseEdition, concurrencyMode }` and throws if `!res.ok`.
- **TTL Envelope Contract (`[firestore.ts:writeData]`, `[firestore.ts:readData]`)**: Every document written via `writeData` carries `ttl = Timestamp.fromMillis(Date.now() + ONE_HOUR_MS)` as a Cloud Firestore TTL cleanup fallback; `readData` requires defined document data (`assert(data, ...)`) and asserts `expect(ttl).toBeInstanceOf(Timestamp)` before returning the remaining fields.
- **Bounded Step Synchronization & Sibling Fast-Abort (`[concurrent.ts:ConcurrentTest.when]`, `[concurrent.ts:ConcurrentTest.run]`)**: `when(...what)` captures `procName` and a call-site `Error` at entry, unconditionally logs `WAITING UNTIL:`, and consumes events from an append-only `events` buffer tracked by reactive `eventVersion$` and a per-process cursor (`matchIdx + 1`) so consecutive `event()` calls never lose intermediate events and repeated event names cannot false-match earlier emissions (while `lastEvent$` remains updated on every `event(what)`). Unmatched calls wait up to `timeout` ms (default `8_000` ms), rejecting with the call-site `Error` containing the full chronological `log` on timeout and always cleaning up `activeWaits` and its timer `AbortController` in `finally`; when any process inside `run(...)` rejects, `run` sets `runFailed` and immediately aborts all active `when(...)` waiters (`ABORT_REASON_SIBLING_FAILED`) so sibling processes fail fast (and subsequent `when(...)` calls throw immediately), awaiting `Promise.allSettled(...)` before rethrowing `firstError`.

## Side Effects

- **Module-Load Client & Hook Registration (`[firestore.ts]`, `[index.ts]`)**: Importing `./utils` reads `process.env.FIRESTORE_EMULATOR_HOST` and `process.env.RUST_EMULATOR`, instantiates three `@google-cloud/firestore` clients targeting project `'firestore-test-406503'` (`(default)`, `'enterprise'`, `'enterprise-pessimistic'`), registers a conditional Jest `beforeAll` hook (`fetch` `PATCH` against `/v1/projects/.../databases/...` on the Rust emulator), and registers Jest `afterAll` hooks invoking `recursiveDelete` (skipping enterprise roots on `JAVA EMULATOR`) followed by `terminate()` on all three `Firestore` clients.
- **Network & Clock I/O (`[firestore.ts:writeData]`, `[firestore.ts:readDataRef]`, `[common.ts:rawRunQuery]`)**: Reads `Date.now()` when constructing fixtures, performs gRPC document reads via `ref.get()`, and on `CLOUD FIRESTORE` invokes a best-effort `rollback` unary RPC in `finally` whenever a `req.newTransaction` `rawRunQuery` stream yields a transaction token (deriving the database root via `req.parent.split('/documents')[0]`).
- **Async Context & Reactive State (`[concurrent.ts:ConcurrentTest]`)**: Binds per-worker labels in `AsyncLocalStorage`, mutates `this.log`, `events`, per-process `cursors`, and `@skunkteam/sherlock` `lastEvent$`/`eventVersion$` state, and schedules `timers/promises` timeouts.
